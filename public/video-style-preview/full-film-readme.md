# The new and improved digital portfolio

Three-minute internal review cut, based on the approved script and 15-second style direction.

## Review files

- `JLL-Digital-Portfolio-Full-1080p.mp4`: full 1920 × 1080 film, 24fps, with original background music and burned-in text. No synthetic narration is included.
- `JLL-Recording-Script.md`: scene-by-scene narration with time markers, ready for your team to record.
- `JLL-Full-Captions.srt`: editable timed text used by the film.

A continuous voice recording in WAV, M4A or MP3 can be added later. Record without background music, and leave short pauses between the script sections. The animation can be retimed to the natural recording rather than making the speaker rush.

## Content

The film begins on the London map with the requested title. It covers development details and videos, nearby stations and route/commute actions, buyer favourites, My Profile and personal links, saved PCL collections, Elizabeth line/station defaults, brochure cover/introduction/personal notes, saved brochures and Outlook attachments, JLL source stock and protected overrides, developer URL draft review, bulk JSON imports, Google Analytics and Team activity.

The bulk format is JSON, up to 200 records per file. Brochure and floor-plan document links on development detail pages remain outside this current-feature film because they are not implemented. The existing personalised PDF brochure builder is demonstrated.

## Example workspace and accuracy

Interface captures use a temporary, deleted local database, a fictional JLL Broker account, an example.test email and a reserved example phone number. No production accounts, stock or settings were changed. No email or WhatsApp message was sent. The example workspace is labelled in staff-screen shots. No production usage figures are invented.

The development data comes from the portfolio's public initial records. External listing image/video hosts and Google Analytics account pages were unavailable in the cloud workspace. The film demonstrates the real detail controls, a supported-video callout and the actual Analytics/Team activity screens; it does not show a live external video or a private GA4 dashboard. Station routes use the real app's route-check fallback; no walking or cycling duration numbers have been fabricated. Developer import review illustrates the actual editable draft using the listing-text fallback, with missing information intentionally left for review. The import caption notes that some sites need manual completion.

The PCL example brochure is generated by the current app. Its own-broker notes are captured from the generated PDF. Its stock photos could not be fetched, so the film's PDF close-ups focus on the cover and the personalised text, not missing photography.

## Edit and preview

The editable Remotion project is in `video/`. Run `npm ci`, then `npm run dev` from that folder and open the URL printed by Studio. Select `JLL-Full-Film`. The full composition is registered in `src/Root.tsx`; scenes and text are authored in `src/FullFilm.tsx` and `public/full-timeline.json`.

The prior 15-second style study remains separately available as `JLL-Style-Draft`. It is not the full film and its old narration is not used by the full composition.

Export with:

```sh
npx remotion render src/index.ts JLL-Full-Film ../JLL-Digital-Portfolio-Full-1080p.mp4 --codec=h264 --crf=21 --audio-codec=aac --audio-bitrate=128k
```

This cloud environment blocks Remotion's bundled browser download. The session renders through Remotion using the installed Chromium as a fallback. On a standard workstation use Remotion's default bundled browser.

## Brand, music and map

The supplied JLL Residential lockups are self-hosted. Display and interface text use Source Sans 3; short editorial callouts use Source Serif 4 Light Italic. Main colours are Midnight #131E29, Space #003E51, Sand #E0C6AD and White. WhatsApp uses its green glyph.

The London map is the approved style-study map, drawn from actual OSM polygons/roads and pre-rasterized at 4800 × 3000 for efficient animation. Its source is the 2012 London extract in https://github.com/alexgraul/TileMillUK . The Elizabeth line and station overlay uses the portfolio's bundled TfL network snapshot. Credits remain visible: © OpenStreetMap contributors and TfL Open Data. This is a geographic illustration, not current live routing data.

The background score and transition accents were synthesized for this film, using no third-party music recording. No AI voice, speech model, voice clone or speech API is used in this full cut.
